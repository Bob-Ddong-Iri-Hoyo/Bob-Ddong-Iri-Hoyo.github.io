## 質問する前に確認すること

- ###### Mac で Eternal Return（エターナルリターン）をプレイできますか？
    - はい。バブトンイリホヨ ランチャーを使用すると、Apple Silicon Mac と macOS 環境で Steam 版 Eternal Return を実行できます。インストール手順は [Steam ゲームのインストールと設定ガイド](../steam-guides/) を参照してください。
- ###### ゲームを起動した後、最初の画面から真っ暗なままです。
    - 初回起動時には通常、現在のシーズンの映像が再生されます。映像の再生に問題があるため、黒い画面で停止したように見えることがあります。`Esc` キーを押すと映像をスキップして先に進めます。
- ###### バブトンイリホヨは CrossOver や Whisky と何が違いますか？
    - 大きな方向性としては、CrossOver や Whisky と大きく異なるものではありません。いずれも Wine ベースの互換環境を使って、Windows プログラムを macOS 上で実行する点は似ています。

      違いは、バブトンイリホヨが Eternal Return と HoYoverse ゲーム向けに Wine と DXMT の構成を調整している点です。特に Eternal Return で発生することがある緑色のフラッシュやエフェクト崩れなどのグラフィック問題を減らすため、カスタム Wine と DXMT の変更を含んでいます。
- ###### どの Windows ゲームでも実行できますか？
    - 他の Windows ゲームの実行を個別に制限しているわけではありません。ただし、このプロジェクトは Eternal Return と HoYoverse ゲーム向けに調整されているため、その他のゲームの互換性や正常な動作は保証・サポートしていません。
- ###### Steam で他のゲームはインストールできますが、起動できません。
    - この使い方はサポート対象外です。このプロジェクトは、すべての Steam ゲームの実行を目的としていません。
- ###### DXVK や GPTK は使えませんか？
    - 使えません。この用途では DXVK は実質的にダウングレードです。GPTK は公開ソースではないため、Eternal Return で発生するバグを修正できません。
- ###### Rosetta がサービス終了するという話がありますが？
    - 将来的には問題になる可能性があります。ゲームを続けたい場合、解決策が出るまではしばらくアップデートを避けた方がよいです。
- ###### Eternal Return で glitch bug が発生する理由は？
    - 根本原因は Apple の Driver 問題です。つまり Apple が修正しない限り、一般の開発者が直接的な原因を修正することはできません。
- ###### Honkai Impact 3rd は動きますか？
    - 動きません。対応していません。
