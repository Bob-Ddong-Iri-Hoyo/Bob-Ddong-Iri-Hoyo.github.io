## Check This Before Asking

- ###### Other games install through Steam, but they do not run.
    - That is how the project is designed.
- ###### Can I use DXVK or GPTK instead?
    - No. DXVK is effectively a downgrade for this use case. GPTK is not open source, so the Eternal Return bugs cannot be fixed there.
- ###### I heard Rosetta is being discontinued. Is that true?
    - It may become a problem later. If you want to keep playing games, you should avoid updating for a while until a solution appears.
- ###### Why does the glitch bug happen in Eternal Return?
    - The root cause is an Apple driver issue. That means regular developers cannot directly fix the underlying cause unless Apple fixes it.
- ###### Does Honkai Impact 3rd work?
    - No. I do not support it.
